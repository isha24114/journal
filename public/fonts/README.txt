Circular Std is a commercial font (Lineto) and isn't included here.

Add your own licensed files with these exact names and the site will pick
them up automatically (see the @font-face rules in app/globals.css):

  CircularStd-Book.woff2    (weight 450 — used for all body copy)
  CircularStd-Medium.woff2  (weight 500 — optional, used if you add it)
  CircularStd-Bold.woff2    (weight 700 — optional, used if you add it)

Until these files are present, body text falls back to the system UI font
stack (San Francisco / Segoe UI / Helvetica Neue), so the page still renders
correctly — line-height (32px), size (18px) and spacing all stay correct,
only the exact typeface differs.
